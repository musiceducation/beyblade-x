🔒 HTTPS 信任設定

現場手機、平板與 OBS 需信任本機 HTTPS 憑證，才能開啟鏡頭、全螢幕與即時查閱。

1. 啟動伺服器

在 Mac 主機執行 ./start.sh，預設網址：

https://本機IP:8443/

2. iPhone / iPad（Safari）

  1. 用 Safari 開啟上方 HTTPS 網址
  2. 若出現「此連線非私人連線」→ 點「顯示詳細資料」→「造訪此網站」
  3. 若要長期信任：設定 → 一般 → 關於 → 憑證信任設定 → 啟用本機憑證（若已安裝描述檔）
  4. 重新整理頁面，確認網址列有鎖頭圖示

3. Android（Chrome）

  1. Chrome 開啟 HTTPS 網址
  2. 警告頁面 →「進階」→「繼續前往…（不安全）」
  3. 若需鏡頭：點網址列鎖頭 → 網站設定 → 允許相機

4. OBS Browser Source

  1. 來源 → 瀏覽器 → 網址填 overlay.html?session=junior&transparent=1&compact=1
  2. 寬度 1920、高度 1080，勾選「自訂 CSS」可留空
  3. 若無法載入：OBS 設定 → 進階 → 關閉「硬體加速」後重試
  4. 叫號看板可用 queue.html
  5. 頒獎典禮背景可用 awards.html?session=junior（決賽完場後自動顯示冠亞軍與四強）

5. 選手查閱（4G 雲端）

無需信任憑證：掃主機「選手查閱 QR」連到 Vercel 雲端入口。場內主機需設定 arena-secrets.local.json 並保持 ./start.sh 運行以同步資料。
